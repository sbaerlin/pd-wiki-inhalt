# Tastenbelegung

> Die hier aufgeführten Tastenbelegungen entsprechen den Standard-Einstellungen von Arma 3 sowie den verwendeten Mods ACE und Task Force Radio. Alle Tasten können in den Einstellungen angepasst werden.

---

# Allgemeine Steuerung (Zu Fuß)

| Taste | Funktion |
|---|---|
| W | Vorwärts bewegen |
| S | Rückwärts bewegen |
| A | Nach links bewegen |
| D | Nach rechts bewegen |
| Shift | Sprinten |
| Strg | Langsam bewegen |
| X | Ducken |
| Y | Hinlegen |
| V | Übersteigen |
| Shift + V | Klettern |
| Alt | Freies Umschauen |
| M | Karte öffnen |
| K | Kompass öffnen |
| O | Uhr anzeigen |
| Windows-Taste | Normales Interaktionsmenü öffnen (Farmen, Ausweis zeigen, etc. |

---

# Inventar & Systeme

| Taste | Funktion |
|---|---|
| I | Normales Inventar öffnen |
| T | Kofferraum öffnen und virtuelles Inventar anzeigen |
| Z | Tablet öffnen und virtuelle Items verwalten |
| Strg + Z | Handy öffnen |

---

# Waffensteuerung

| Taste | Funktion |
|---|---|
| Linke Maustaste | Schießen |
| Rechte Maustaste | Zielen |
| R | Nachladen |
| F | Feuermodus wechseln |
| Shift + Rechte Maustaste | Luft anhalten |
| Bild hoch / Bild runter | Visierentfernung einstellen |
| 2× Strg | Waffe senken / anheben |
| Shift + H | Waffe ins Holster stecken |
| Strg + H | Waffe aus dem Holster holen |

---

# Fahrzeugsteuerung

| Taste | Funktion |
|---|---|
| W | Beschleunigen |
| S | Bremsen / Rückwärts fahren |
| A | Nach links lenken |
| D | Nach rechts lenken |
| Shift | Schneller fahren / stärker beschleunigen |
| X | Handbremse |
| T | Kofferraum öffnen |
| Bild hoch | Tempomat erhöhen |
| Bild runter | Tempomat verringern |

---

# ACE-Interaktionen

| Taste | Funktion |
|---|---|
| Windows-Taste | ACE-Interaktion öffnen |
| Strg + Windows-Taste | ACE-Selbstinteraktion öffnen |
| H | ACE-Sanitätsmenü öffnen |

---

# Task Force Radio (TFAR)

| Taste | Funktion |
|---|---|
| Caps Lock | Funk sprechen |
| Strg + P | Funkgerät öffnen |
| Strg + Tab | Sprachlautstärke wechseln |

---

# Hinweise

- Viele Funktionen können serverabhängig angepasst oder erweitert sein.
- ACE und Task Force Radio erweitern Arma 3 um realistische Interaktionen und Funkkommunikation.
- Tablet, Handy und virtuelle Inventare sind serverspezifische Erweiterungen.
- Die Windows-Taste ist standardmäßig doppelt belegt (normales Interaktionsmenü und ACE-Interaktion). Es wird empfohlen, eine der beiden Funktionen umzubelegen.
- Die normale Interaktion kann unter `Steuerung → Individuelle Steuerung 10` geändert werden.
